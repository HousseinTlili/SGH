# Agent instructions

This repository is the SGH hospital management system (six microservices, one gateway, one Angular front end).

1. Read `GUIDELINES.md` (working rules, layout, conventions) first. It applies to every developer and agent.
2. Read `docs/ANTIGRAVITY-HANDOFF.md` (what exists, what to build, in which order, how to verify). Follow its task list in order.
3. The specification is in Notion (read only). The key pages and their URLs are listed in the handoff, section 1.
4. Never push to or merge into `main`. One task, one branch, one pull request.
